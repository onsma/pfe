================================================================================
  BFPME — HOW TO LAUNCH THE PROJECT
  (run these steps every time you start a new session)
================================================================================

REQUIREMENTS
------------
  - Python 3.13  (C:\Python313\python.exe)
  - Ollama 0.30+  (ollama.exe must be in PATH)
  - Model downloaded: qwen2.5:7b  (4.7 GB)
  - All pip dependencies installed in backend/  (see STEP 0)


================================================================================
  STEP 0 — ONE-TIME SETUP  (skip after first run)
================================================================================

Open a PowerShell terminal and run:

    cd c:\pfe\backend
    python -m venv .venv
    .venv\Scripts\Activate.ps1
    pip install -r requirements.txt

This installs FastAPI, uvicorn, XGBoost, SHAP, scikit-learn, httpx, etc.
The virtual environment lives at c:\pfe\backend\.venv — activate it
(.venv\Scripts\Activate.ps1) in every new terminal before running uvicorn.


================================================================================
  STEP 1 — START OLLAMA  (Terminal 1)
================================================================================

First check if Ollama is already running:

    ollama list

  - If you see qwen2.5:7b in the list → Ollama is already running, SKIP to STEP 2.
  - If you get a connection error → start it manually:

    ollama serve

    Leave this terminal open. You should see:
        Listening on 127.0.0.1:11434

NOTE: On Windows, Ollama often starts automatically at login as a system tray
      app. The error "bind: Une seule utilisation..." means it is already
      running — that is fine, do not start a second instance.


================================================================================
  STEP 2 — VERIFY THE LLM MODEL IS AVAILABLE
================================================================================

In any terminal run:

    ollama list

You must see:  qwen2.5:7b

If it is missing, pull it again:

    ollama pull qwen2.5:7b


================================================================================
  STEP 3 — FREE PORT 8000 IF NEEDED  (skip if port is free)
================================================================================

Check whether port 8000 is already in use:

    netstat -ano | findstr ":8000"

If you see a result, note the PID in the last column and kill it:

    taskkill /PID <PID> /F

Example:
    netstat -ano | findstr ":8000"
    →  TCP  0.0.0.0:8000  ...  LISTENING  12345
    taskkill /PID 12345 /F


================================================================================
  STEP 4 — START THE BACKEND  (Terminal 2)
================================================================================

Open a NEW PowerShell terminal and run:

    cd c:\pfe\backend
    .venv\Scripts\Activate.ps1
    python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

Wait until you see:

    INFO:     Application startup complete.
    INFO:     Uvicorn running on http://0.0.0.0:8000

Leave this terminal open. The --reload flag auto-restarts on code changes.

IMPORTANT: The .env file at c:\pfe\backend\.env controls all settings.
           Current configuration:
             LLM_ENABLED   = true
             LLM_MODEL     = qwen2.5:7b
             LLM_BASE_URL  = http://127.0.0.1:11434/v1
             MODEL_ARTIFACT_PATH = c:/pfe/data/option_c_xgboost_model.joblib


================================================================================
  STEP 5 — OPEN THE DASHBOARD
================================================================================

Open your browser and go to:

    http://127.0.0.1:8000/dashboard        ← main dashboard (HTML/JS UI)
    http://127.0.0.1:8000/docs             ← Swagger UI (all API endpoints)
    http://127.0.0.1:8000/health           ← quick health check

================================================================================
  OPTIONAL — RETRAIN THE MODEL
================================================================================

If you want to retrain XGBoost on a new dataset:

    cd c:\pfe
    python scripts\train_option_c_xgboost.py

Then reload the artifact without restarting the server:

    Invoke-RestMethod -Uri "http://127.0.0.1:8000/metadata/reload-model" -Method Post

================================================================================
  TROUBLESHOOTING
================================================================================

Problem:  "uvicorn: command not found"
Fix:      Use  python -m uvicorn  instead of  uvicorn  directly.

Problem:  500 Internal Server Error on /predict
Fix:      Check that code_modele is an integer (1 or 2), not a string like "A".
          Missing features are auto-imputed — you do not need to send all fields.

Problem:  LLM call times out
Fix:      Ollama may still be loading the model. Wait 60s and retry.
          If it persists, run  ollama serve  in a separate terminal.

Problem:  Port 8000 already in use
Fix:      See STEP 3 above.

Problem:  Model artifact not found
Fix:      Check that  c:\pfe\data\option_c_xgboost_model.joblib  exists.
          If missing, retrain:  python scripts\train_option_c_xgboost.py
