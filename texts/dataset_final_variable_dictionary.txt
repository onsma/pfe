BFPME - Dataset Final Variable Dictionary and Business Logic
===========================================================

File concerned:
- data/dataset_final.csv

Purpose of the dataset
----------------------
This dataset was built as an enriched, centralized dataset for credit-risk modeling.
It starts from the existing synthetic BFPME score dataset and adds business, financial,
behavioral, guarantee, and macroeconomic variables so that it can serve as a realistic
starting point for binary default classification.

Main modeling objective
-----------------------
- Target for classification: default_flag
- Intermediate latent probability: pd_target

Important note
--------------
The dataset is synthetic. It does not represent observed real defaults. It is a
business-driven simulation designed to be coherent enough for:
- prototyping,
- model comparison,
- feature engineering,
- classification workflows,
- credit-risk use cases such as PD-style modeling.


1. OVERALL GENERATION LOGIC
===========================

The dataset was generated with a hidden business driver:
- latent_risk
- latent_quality = 1 - latent_risk

This hidden risk driver is not random noise only. It is derived primarily from:
- the BFPME score,
- the BFPME risk class,
- the model type (creation vs extension),
- a small random shock to avoid deterministic rows.

Business meaning:
- better BFPME score -> lower latent risk
- worse BFPME class -> higher latent risk
- creation projects are slightly riskier on average than extension projects

Then, almost all new variables are generated conditionally on this hidden profile.
This makes the dataset coherent:
- stronger firms tend to have better liquidity, governance, guarantees, repayment behavior
- weaker firms tend to have worse payment behavior, higher leverage, weaker market position


2. ORIGINAL BFPME VARIABLES KEPT IN THE DATASET
===============================================

Base identifiers
----------------
- dossier_id: unique synthetic dossier identifier
- code_modele: BFPME scoring model code
  - 1 = projet en creation
  - 2 = projet en extension
- risk_class: original BFPME risk class from the base synthetic dataset

Original BFPME scores
---------------------
- score_bfpme_good: score under the "good" scenario from the original synthetic dataset
- score_bfpme_average: score under the "average" scenario from the original synthetic dataset

Derived BFPME score features
----------------------------
- score_bfpme_global:
  selected global BFPME score used as a feature
  - if code_modele = 1 -> score_bfpme_average
  - if code_modele = 2 -> score_bfpme_good

- score_bfpme_gap:
  difference between score_bfpme_good and score_bfpme_average
  useful as a proxy for score sensitivity or uncertainty

- bfpme_risk_index:
  numerical mapping of BFPME class into a risk scale
  - Excellent = 0.08
  - Bon = 0.22
  - Moyen = 0.45
  - Risque = 0.68
  - Tres_Risque = 0.85
  - Rejete = 0.97

Original sub-factors
--------------------
- SF_1 ... SF_62:
  original BFPME sub-factor columns copied from the base synthetic dataset.
  They preserve the scorecard structure and can be reused for rule-based or ML analysis.


3. BFPME-RELATED SYNTHETIC ENRICHMENTS
======================================

- score_financier_bfpme:
  proxy of the BFPME financial factor score

- score_business_bfpme:
  proxy of the BFPME business factor score

- score_management_bfpme:
  proxy of the BFPME management factor score

- score_industrie_bfpme:
  proxy of the BFPME industry factor score

Why these were created:
- to have more granular BFPME-style information,
- to let future models use both total score and score decomposition,
- to mimic how banks often keep factor-level score contributions.

- variation_score_12m:
  synthetic 12-month change in BFPME score

- tendance_score:
  categorical trend derived from variation_score_12m:
  - amelioration
  - stable
  - degradation

Business logic:
- better quality firms tend to improve or remain stable,
- weaker firms more often degrade.

- marge_nette_pct

- weak profiles can generate low or even negative net results

Cash flow
---------

Logic:
- stronger profiles tend to have better access to credit and slightly higher chance of support


10. DERIVED FINANCIAL RATIOS
============================

- ratio_fdr_bfr:
  FDR / BFR ratio

- ratio_liquidite_generale:
  current ratio = actifs_courants / passifs_courants

- quick_ratio:
  immediate liquidity ratio excluding inventory

- debt_to_equity_ratio:
  leverage ratio

- dscr:
  debt service coverage ratio

- interets_sur_ebitda:
  interest burden relative to EBITDA

- garantie_coverage_ratio:
  collateral value / loan amount

- apport_ratio:
  personal contribution / total investment

- ratio_cout_credit:
  total credit cost / loan amount

Why these ratios matter:
- they are standard credit-risk indicators
- they create meaningful numerical signals for classification models
- they align with how banks assess solvency, liquidity, leverage, and protection

13. TARGET VARIABLES
====================

- pd_target:
  synthetic default probability between 0 and 1

- default_flag:
  binary target for classification
  generated by drawing a Bernoulli event from pd_target
  - 1 = default
  - 0 = non-default

Important modeling note:
- for binary classification, use default_flag as the target
- do not use pd_target as an input feature, because it directly leaks the target logic


14. HOW pd_target WAS CONSTRUCTED
=================================

The synthetic probability of default was generated from a latent default score.

Variables increasing default risk
---------------------------------
- low BFPME score
- poor BFPME class
- higher dpd_moyen
- high leverage (debt_to_equity_ratio)
- weak debt service capacity (low dscr)
- poor payment behavior
- debt restructurings
- sudden debt increase
- deposit decrease
- adverse macro conditions
- higher sector/country stress

Variables reducing default risk
-------------------------------
- higher liquidity ratios
- stronger collateral coverage
- better on-time repayment rate
- stronger institutional confidence

Then the latent score is transformed with a sigmoid function to obtain:
- pd_target in [0, 1]

Finally:
- default_flag is sampled from pd_target


15. WHY THIS DATASET IS BUSINESS-CONSISTENT
===========================================

This dataset was intentionally built to avoid purely random independent columns.
Instead, most variables are linked through a hidden business profile.

Examples of coherence:
- a good borrower tends to have:
  - better BFPME score
  - higher equity
  - better liquidity
  - lower DPD
  - stronger guarantees
  - better governance
  - better repayment discipline

- a weak borrower tends to have:
  - lower BFPME score
  - higher leverage
  - worse DPD
  - more stress signals
  - weaker guarantees
  - lower institutional trust

This makes the dataset more realistic for:
- preprocessing,
- feature selection,
- model training,
- binary classification experiments,
- explainability exercises.


16. RECOMMENDED MODELING USAGE
==============================

Recommended target:
- default_flag

Recommended exclusions from model inputs:
- pd_target

Optional exclusions depending on objective:
- risk_class, if you want to avoid too much direct rule-based leakage
- score_bfpme_global, if you want a model independent from BFPME

Recommended first use cases:
- Logistic Regression
- Random Forest
- XGBoost / Gradient Boosting

Recommended first checks:
- class balance
- missing values
- categorical encoding
- target leakage review
- calibration and ROC/AUC evaluation


17. FINAL INTERPRETATION
========================

This dataset is not a regulatory or accounting-grade IFRS 9 production dataset.
It is a synthetic, business-driven prototype dataset designed to:
- show project value,
- support a proof of concept,
- compare classification models,
- prepare later transition toward real PD/default data.
